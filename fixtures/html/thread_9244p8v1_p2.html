RayMondo writes...

For some reason notifications don't seem to be coming through very timely today, if at all. Still getting them from Whirldroid though.

What do you have the background check interval set at? The default is 1 hour, but it can be set at 15 mins. The options are the same as Whirldroid. The background update is somewhat managed by the system so that it isn't overly taxing on battery life. The interval is a request to the system for an update to happen in that period. It could happen at the start or closer to the end. So consecutive checks could be close to two periods apart in some situations. Battery status and sleep configurations could also delay it.

I'll make a couple of changes to tighten the interval, and to make it easier to see when background checks are taking place.

Meanwhile, Whirl 1.3 and 1.4 (and 1.4.1) are out.

1.3: Find in list (thanks RayMondo) I for the idea)
A search icon at the top of Watched, Recent, Latest activity, Popular, a forum, Forums and Industry news filters the list as you type. Every word has to appear in the thread title or the forum/group name, and case and accents don't matter. Forums also matches section names, and news matches the source and summary.

On a forum it filters the page you're on. To look further, the "Search Whirlpool for …" button under the box searches the site for the same words: within that forum when you're in one, site-wide everywhere else. On Forums and forum pages this replaces the old search icon.

On Watched's Unread tab, if nothing unread matches, "Show N in All" takes you to the All tab with the same filter.

The filter stays put while you read a thread and come back. The back arrow clears it.

With a keyboard: Ctrl+F or / to find, Esc to close.

1.4: Tablets (experimental)
Settings > Layout > "Threads beside the list (experimental)": on a tablet, an unfolded phone or another wide window, a thread opens next to the list it came from, and tapping another thread swaps it. Phones are unchanged, including in landscape. It's off by default because I've only tried it on an emulator, so if you have a tablet or foldable, please turn it on and tell me how it goes.

Navigation was rebuilt underneath to make that possible. Everything should work as before, but shout if anything feels off.

1.4.1 adds a couple of links to the about page – this thread, and the Google Play listing.

Download: https://github.com/dalbo/whirl/releases/latest (APK), or update through Google Play if you're in the closed test.

Version 1.5.1 is available now

  • RayMondo:
    • "Threads beside the list" should now work on the Fold7's inner screen (it's still off by default, so it needs to be enabled in settings).
    • A thread's ⋮ menu also has "Watched threads" now.
  • leo27:
    • there's a new "Only in landscape" option under "Threads beside the list".
    • The panes are now split by a thin line instead of the white bar, Forums shows as a list with an empty pane beside it, and threads opened at their last page land on the newest post.

For the next release I'll look at

  • Mark all Read for Watched threads
  • Potentially a longer undo period (and making this more reliable if the app closes, etc)
    • The confirmation popup is probably simpler, but I'm not really a fan of adding it for a routine action.
  • A scrollbar

leo27: for "Find in a thread", this is straight forward to search within the current page of a thread. But at the moment we don't have the full thread available, and WP doesn't provide an API or page for searching the full thread. I have considered adding an "archive" view, which allows browsing threads using the much longer pages from the archive UI. Building on that may allow for searching much larger sections of the thread. But considering the length of some of the longest threads, I'm not sure that a full search of the whole thread is a great idea. Does searching the current page (normal size, or archive size) meet your use case?
