Whirlcode

Whirlcode is a way of formatting text on Whirlpool. It can be used to format forum posts and wiki pages.

Inline formatting

Bracket markers wrap text in the same paragraph. Spaced hyphens become dashes. Where a simple HTML tag is allowed, it is listed as an alternative.

WhirlcodeHTML alternativeResult, notes
[*bold*]<strong> <b>bold
[/italic/]<em> <i>italic
[(small)]<small>small
[-strike-]<strike>strike
[#monospace#]<tt>monospace
[~serif~]serif
H[\2\]O<sub>H2O (subscript)
500m[^2^]<sup>500m2 (superscript)
["forum quote"]forum quote, for quoting posts on Whirlpool
['external quote']external quote, for quoting other material, e.g. a news article
[`alternate quote`]alternate quote
[_spoiler_]spoiler for hiding spoliers
[?google search?]google search, links to a Google search for the enclosed terms
[[whirlcode]]<a href="/wiki/…">whirlcode, links to the wiki entry for that term
[[whirlcode|label]]<a href="/wiki/…">[[whirlcode|label]], same as above, but with different text
[.*escaped*.][*escaped*], for showing Whirlcode without rendering it
-&ndash;– (spaced hyphen becomes en dash)
--&mdash;— (spaced double-hyphen becomes em dash)

To show Whirlcode without rendering it, wrap the markers with a leading and trailing full stop inside the brackets — e.g. [.*like this*.].

While inside a table cell, a | always splits table cells. To put a literal pipe in a table cell, write &#124; or &vert; because characters that are written as HTML entities will never become Whirlcode.

Links and HTML

Web and email addresses are linked automatically. Whirlpool and whrl.pl short links are treated as internal.

For custom link text, use <a href="https://www.google.com.au">Google</a> — only an href attribute is permitted on <a>. Other allowed tags are listed under Inline formatting above.

Block structure

These apply at the start of a line. Spaces between structural codes are optional, but a space is required between the last structural code and printed text.

PrefixPurpose
:Indent / quote
*
**
***		Bullet list (up to 3 deep)
#
##
###		Numbered list (up to 3 deep)
>
>>
>>>		Coloured reply quote (up to 3 deep)
=
==
===		Wiki headings (wiki only)
$ Preformatted / code (rest of line)
$$Fenced code block (line is only $$; next $$ closes, or EOF)
-----Horizontal rule (alone on the line)
@id nameJump link to a reply

Lists and quotes can nest, within limits: at most one : layer, three > layers, three of any list marker, and four structural codes total.

Tables

Start a line with a pipe. Cells are split on | (spaces around the pipe are optional). Cells cannot contain a literal pipe.

A Markdown-style separator under the first row makes that row a header. Colons in the separator set alignment (:--- left, :---: centre, ---: right):

| Left | Centre | Right
| :--- | :---: | ---:
| a | b | c

LeftCentreRight
abc

Without a separator row, every row is a normal cell row:

| a | b
| c | d

ab
cd
